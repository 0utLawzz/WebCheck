# WebCheck

Practical pre-launch verification guide for websites and web applications.

## Core Question
I built my website/app. Before I put it online, exactly what do I need to check, where do I go, what should I see, and how do I know it passed?

## Working Method
WHAT → WHY → EXAMPLE → WHERE/HOW → WHAT IT SHOULD LOOK LIKE → PASS/FAIL → COMMON MISTAKE → ACTION

This repository is the source of truth for research, verification evidence, screenshots, and the eventual book manuscript.

## Status
Foundation initialized. Research and verification labs have not yet begun.

## Repository Areas
- MASTER/ — canonical project and book records
- LABS/ — small, real-world verification exercises
- RESEARCH/ — research notes and supporting material
- SCREENSHOTS/ — verified visual evidence
- MANUSCRIPT/ — eventual book draft and final manuscript

## Evidence Rule
Current screenshots and observations must come from actual tools/workflows used during research. Never invent a screen, path, result, or pass condition.

## Verification Rule
A check is not considered verified merely because it sounds correct. Record what was actually observed, when it was verified, and any limitations.

Do not store passwords, API keys, access tokens, or other secrets in this repository.

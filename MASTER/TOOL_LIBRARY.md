# Tool Library

Record tools and platforms actually used during research.

## Standard Tool Record
- TOOL / PLATFORM
- PURPOSE
- ACCOUNT / PLAN CONTEXT
- EXACT PATHS USED
- ACTIONS PERFORMED
- OBSERVED RESULT
- SCREENSHOT REFERENCES
- LIMITATIONS
- LAST VERIFIED
- STATUS

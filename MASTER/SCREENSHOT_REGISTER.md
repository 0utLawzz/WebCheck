# Screenshot Register

Screenshots are evidence, not decoration.

## Standard Record
- SCREENSHOT ID
- CHECK ID
- TOOL / PLATFORM
- EXACT PATH
- IMAGE FILE
- CAPTION
- WHAT THE IMAGE SHOWS
- WHAT THE READER SHOULD LOOK FOR
- VERIFIED DATE
- STATUS
- NOTES

## Status
VERIFIED, NEEDS RECHECK, REPLACED, PARKED

## Screenshot Rules
1. Prefer current screenshots captured during the actual lab.
2. Never expose passwords, API keys, tokens, private customer data, or other secrets.
3. Mask sensitive values without hiding the UI elements the reader needs to understand.
4. Record the verification date.
5. If a platform UI changes, mark the screenshot NEEDS RECHECK rather than silently treating it as current.

# Check Library

Canonical library of launch-readiness checks.

## Standard Check Record
- CHECK ID
- CATEGORY
- CHECK NAME
- WHAT
- WHY
- EXAMPLE
- OPTION A
- OPTION B
- EXACT PATH
- SCREENSHOT REQUIRED
- SCREENSHOT DESCRIPTION
- PASS CONDITION
- FAIL CONDITION
- COMMON MISTAKE
- ACTION
- SOURCE / REFERENCE
- LAST VERIFIED
- STATUS

## Status Values
DRAFT, RESEARCHING, VERIFIED, NEEDS RECHECK, PARKED, OUT OF SCOPE

## Initial Categories
### Universal Launch Checks
Purpose clarity; content completeness; navigation; mobile responsiveness; browser compatibility; performance; SEO basics; accessibility basics; legal/trust basics where applicable; deployment basics.

### Static Website
Complete pages; real content; links; responsive layout; 404; favicon; metadata; sitemap; robots; HTTPS; performance; deployment.

### Dynamic Web App
Authentication; sessions; CRUD; permissions; database behavior; environment variables; API authorization; direct URL access; validation; duplicate submissions; failure/recovery behavior.

### E-Commerce
Product data; cart; checkout; payment states; duplicate payment protection; webhooks/callbacks; order creation; inventory; failed/pending/cancelled/successful payments.

### Blog / Content Website
Publishing; categories/tags; search; images; metadata; sharing; pagination; old URLs; draft/published behavior; admin permissions.

### Business / Lead Website
Contact forms; email delivery; spam protection; phone/WhatsApp CTAs; confirmation; duplicate leads; notifications; lead destination.

### Membership / Portal
Registration; login/logout; roles; permissions; private pages; profile; subscription state where applicable; admin controls; account deletion/privacy.

## Rule
Do not turn this into a giant checklist based on assumptions. Checks become canonical only after research and verification.

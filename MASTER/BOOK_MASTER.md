# Book Master

## Working Title
WebCheck

## Core Promise
A practical, screenshot-driven guide for checking a website or web application before launch.

The reader should be able to answer: What exactly do I check, where do I go, what should I see, and how do I know it passed?

## Differentiator
Move beyond abstract advice. Connect each requirement to an actual action and observable result:
WHAT → WHY → EXAMPLE → WHERE/HOW → WHAT IT SHOULD LOOK LIKE → PASS/FAIL → COMMON MISTAKE → ACTION

## Main Book Structure
1. Universal Launch Checks
2. Static Website
3. Dynamic Web App
4. E-Commerce
5. Blog / Content Website
6. Business / Lead Website
7. Membership / Portal

## Editorial Rules
- Prefer exact click paths over vague instructions.
- Use real examples.
- Use current screenshots where a visual materially helps.
- Clearly distinguish observed facts from general guidance.
- Never invent current UI labels or tool behavior.
- Record verification dates.
- Never expose real credentials or secrets.
- Keep the book practical and task-oriented.
